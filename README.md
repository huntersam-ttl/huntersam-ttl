## How I like to build

I used to spend too much time thinking about what I *could* build.

I'm trying to replace that with a simpler loop:

```text
Notice a problem
      ↓
Understand it
      ↓
Build something small
      ↓
Ship it
      ↓
Talk to real people
      ↓
Learn
      ↓
Improve
```

For AI-assisted development, I increasingly work with autonomous execution loops:

```text
Goal
 ↓
Inspect
 ↓
Plan
 ↓
Implement
 ↓
Test
 ↓
Review
 ↓
Fix
 ↓
Verify
 ↓
Commit
 ↓
Continue until done
```

The agent shouldn't decide that the job is finished.

**The definition of done should.**
